## Recommendation

Use **finite-dimensional CLTs + uniform ℓ¹-tail control + tightness**. For Gaussian existence, first try **extracting a weak limit of the empirical laws themselves**. This avoids constructing a correlated Gaussian sequence, Kolmogorov extension, and infinite-dimensional covariance factorisation.

The cheapest honest intermediate result is:

> **Finite-dimensional convergence to a supplied ℓ¹-valued target, together with uniform tail control, implies convergence in distribution in ℓ¹.**

That is a worthwhile unconditional theorem about the upgrade, but **does not by itself close item 4**: target existence and finite-dimensional CLTs must subsequently be discharged.

Below are eight units, in recommended implementation order. Lean declarations are **interface sketches**, not claims about exact identifiers or elaboration on your pin.

---

## 1. Coordinate/truncation infrastructure and the precise moment hypothesis

Work generically over a countable index, not initially over multi-indices.

```lean
abbrev L1Seq (ι : Type*) :=
  lp (fun _ : ι => ℝ) 1
```

Use `[Countable ι] [DecidableEq ι]`, with an explicit increasing finite exhaustion `F : ℕ → Finset ι`. This avoids committing the probability proof to a particular enumeration.

Implement continuous linear maps:

```lean
coord       (j : ι) : L1Seq ι →L[ℝ] ℝ
truncate    (F : Finset ι) : L1Seq ι →L[ℝ] L1Seq ι
finiteCoords (F : Finset ι) :
  L1Seq ι →L[ℝ] EuclideanSpace ℝ F
```

Required identities:

- `truncate F x` agrees with `x` on `F` and is zero outside;
- `‖x - truncate F x‖ = ∑' j, if j ∈ F then 0 else |x j|`;
- `truncate (F k) x → x`;
- `‖truncate F x‖ ≤ ‖x‖`.

### Recommended CLT hypothesis

For `Y : Ω → L1Seq ι`, require strong measurability up to null sets, coordinate `MemLp 2`, and

\[
\sum_j r_j<\infty,\qquad
r_j=\left(\int |Y_j|^2\,dP\right)^{1/2}.
\]

For example:

```lean
def coordL2 (P : Measure Ω) (Y : Ω → L1Seq ι) (j : ι) : ℝ :=
  Real.sqrt (∫ ω, (Y ω j)^2 ∂P)

structure SummableCoordL2
    (P : Measure Ω) (Y : Ω → L1Seq ι) : Prop where
  aestronglyMeasurable : AEStronglyMeasurable Y P
  memLp_coord : ∀ j, MemLp (fun ω => Y ω j) 2 P
  summable : Summable (coordL2 P Y)
```

An `eLpNorm ... |>.toReal` formulation is equally valid, but keep `MemLp` explicitly so that `toReal ∞ = 0` cannot hide a missing integrability assumption.

**Why use uncentred coordinate L² norms?** They immediately imply Bochner integrability:

\[
E\|Y\|_1=\sum_j E|Y_j|\le \sum_j r_j.
\]

The centred standard deviations satisfy `σ j ≤ r j`. This is slightly stronger than a centred-only hypothesis but substantially cleaner and matches the Cauchy-envelope application.

**Inputs:** `lp` norm and evaluation lemmas, continuous-linear-map integration, Tonelli/`lintegral_tsum`, `MemLp` on probability spaces.

**Measurability trap:** prove coordinatewise-measurable-to-ℓ¹-measurable once, using measurable finite truncations and pointwise convergence. Do not repeatedly unfold `lp` membership.

## 2. The reusable ℓ¹ upgrade with a supplied target

Prove this before developing Gaussian machinery.

Let `S : ℕ → Ω → L1Seq ι` and `G : Ω' → L1Seq ι` be a.e. measurable, on probability spaces. Assume:

1. For every exhaustion stage `k`,
   ```lean
   TendstoInDistribution
     (fun n ω => finiteCoords (F k) (S n ω))
     atTop
     (fun ω' => finiteCoords (F k) (G ω'))
     (fun _ => P) P'
   ```
2. Uniform tail smallness:
   \[
   \forall \varepsilon,\delta>0,\ \exists k,\ \forall n,\quad
   P(\|S_n-T_kS_n\|>\varepsilon)\le\delta.
   \]

Conclude:

```lean
TendstoInDistribution S atTop G (fun _ => P) P'
```

Also expose an L¹-tail corollary with hypothesis

\[
\sup_n E\|S_n-T_kS_n\|\le t_k,\qquad t_k\to0.
\]

### Proof route

Establish tightness using finite-dimensional tightness and tail constraints. A suitable compact set is built from:

- a norm bound;
- a sequence of constraints `‖x - T_{k_j} x‖ ≤ ε_j`, where `ε_j → 0`.

Closedness plus uniform approximation by bounded finite-dimensional sets gives compactness. Use summable exceptional-probability budgets.

Then identify convergence using the supplied target and finite-coordinate cylinder characteristic functions. Your known

`ProbabilityMeasure.tendsto_of_tight_of_separatesPoints`

is a plausible endpoint: use the star-algebra generated by finite-coordinate characters. Check its exact function-space interface before committing.

An existing bounded-Lipschitz characterization would make the proof shorter, if present.

**Important:** your `tendstoInDistribution_of_approx` for modification on small-probability events is **not** the needed approximation theorem. Small distance is not equality outside a small event.

**Deliverable label:** “ℓ¹ convergence upgrade,” not “empirical-process CLT.”

## 3. Finite-dimensional i.i.d. CLT

Target finite-dimensional real inner-product spaces, or initially just `EuclideanSpace ℝ (Fin m)`.

A practical public interface is:

```lean
-- E finite-dimensional real inner-product space
-- X : ℕ → Ω → E, Z : Ω' → E
theorem iid_clt_finiteDimensional
    (hXmeas : ∀ i, AEStronglyMeasurable (X i) P)
    (hX2 : MemLp (X 0) 2 P)
    (hindep : iIndepFun X P)
    (hident : ∀ i, IdentDistrib (X i) (X 0) P P)
    (hZ : HasLaw Z targetGaussian P') :
    TendstoInDistribution
      (fun n ω =>
        (Real.sqrt (n : ℝ))⁻¹ •
          ∑ i ∈ Finset.range n, (X i ω - ∫ ω, X 0 ω ∂P))
      atTop Z (fun _ => P) P'
```

Here `targetGaussian` must be constructed with covariance

\[
Q(s,t)=E[\langle s,X_0-m\rangle\langle t,X_0-m\rangle].
\]

### Proof

For fixed `t`, apply the existing scalar CLT to `ω ↦ ⟪t, X i ω⟫`. Transport independence and identical distribution by the same measurable linear functional. Then use

`ProbabilityMeasure.tendsto_iff_tendsto_charFun`.

You also need:

- Bochner expectation commutes with the linear functional;
- projected target law has variance `Q(t,t)`;
- scalar finite-sum centring agrees with the scalar CLT’s `sum − n * mean`.

**Gaussian target trap:** inspect the definition of `multivariateGaussian μ S`. Do not assume its second argument is the covariance rather than a covariance factor, or that positivity assumptions are implicit. Prove an explicit covariance/characteristic-function specification and hide construction details behind it.

**Inputs:** the listed scalar CLT and Lévy theorem, `HasLaw` transport, `IdentDistrib` transport, `iIndepFun` composition, multivariate Gaussian characteristic functions, covariance positivity.

This unit is reusable Mathlib-quality infrastructure.

## 4. Uniform empirical tail estimates

For i.i.d. `Y : ℕ → Ω → L1Seq ι`, with Unit 1’s hypothesis on `Y 0`, define

```lean
noncomputable def empiricalCentered
    (Y : ℕ → Ω → L1Seq ι) (P : Measure Ω)
    (n : ℕ) (ω : Ω) : L1Seq ι :=
  (Real.sqrt (n : ℝ))⁻¹ •
    ∑ i ∈ Finset.range n, (Y i ω - ∫ ω, Y 0 ω ∂P)
```

Let

\[
\sigma_j=\sqrt{E[(Y_{0,j}-EY_{0,j})^2]}.
\]

Prove the central estimate:

```lean
∫ ω, ‖empiricalCentered Y P n ω -
        truncate F (empiricalCentered Y P n ω)‖ ∂P
  ≤ ∑' j, if j ∈ F then 0 else σ j
```

and consequently the same bound with `r j`.

For each coordinate:

- independence gives zero cross terms;
- for `n > 0`, the normalized sum has second moment `σ j ^ 2`;
- Cauchy–Schwarz gives its first absolute moment at most `σ j`;
- Tonelli sums over coordinates.

Handle `n = 0` separately: the empirical sum is zero, so the inequality remains valid, although the second-moment equality generally does not.

Also obtain the uniform norm bound

\[
\sup_n E\|S_n\|_1\le\sum_j\sigma_j.
\]

**Inputs:** independence/integral-product lemmas, variance of sums if convenient, `MemLp` arithmetic, finite-sum integration, Markov’s inequality.

**Normalisation trap:** keep sample size in `ℕ` and explicitly cast to `ℝ`. This proves a sequence CLT; it does not automatically provide a theorem indexed by arbitrary real `N`.

## 5. Gaussian existence by tightness—not by a correlated product measure

### Preferred route

Use Unit 4 to prove tightness of the empirical laws. Extract a subsequential weak limit `ν : ProbabilityMeasure (L1Seq ι)`. Unit 3 identifies every finite-dimensional marginal of `ν` as the required centred Gaussian.

This constructs the limit and its covariance without ever constructing a Gaussian process on a product space.

**First grep gate:** locate the theorem that a tight sequence of probability measures on a Polish space has a weakly convergent subsequence. Do not assume the existence of `tight_of_tendsto_polish` supplies the reverse implication.

The separating-algebra theorem you listed can identify convergence **to an existing measure**; it does not itself create that measure.

### Precise existence target

```lean
∃ ν : ProbabilityMeasure (L1Seq ι),
  (∀ F : Finset ι,
    Measure.map (finiteCoords F) (ν : Measure (L1Seq ι))
      = finiteGaussianLaw Y P F)
```

Prefer to prove at the same time that `ν` is a subsequential limit of the empirical laws.

### Fallback ranking

1. **Available Prokhorov subsequence theorem:** best.
2. **A small missing probability-measure compactness wrapper:** reasonable bounded addition.
3. **Known-target upgrade from Unit 2, with target existence explicit:** honest partial stopping point.
4. **Countable Gaussian construction via Gram–Schmidt/Cholesky:** mathematically valid, but a separate infrastructure project.

`Measure.pi` of coordinate Gaussians is not the answer: it loses the off-diagonal covariance. Merely having `IsGaussianProcess` or `HasGaussianLaw` definitions also does not establish covariance-kernel existence.

## 6. Package the full ℓ¹ CLT and identify its law

Combine Units 2–5:

```lean
theorem iid_clt_l1_of_summableCoordL2
    (hYmeas : ∀ i, AEStronglyMeasurable (Y i) P)
    (hY2 : SummableCoordL2 P (Y 0))
    (hindep : iIndepFun Y P)
    (hident : ∀ i, IdentDistrib (Y i) (Y 0) P P) :
    ∃ ν : ProbabilityMeasure (L1Seq ι),
      TendstoInDistribution
        (empiricalCentered Y P)
        atTop
        (id : L1Seq ι → L1Seq ι)
        (fun _ => P)
        (ν : Measure (L1Seq ι))
      ∧ GaussianCoordinateSpecification ν Y P
```

Using the canonical target probability space `(L1Seq ι, ν)` avoids an unnecessary Gaussian-realisation theorem on a preselected `Ω'`.

`GaussianCoordinateSpecification` should record:

- every finite-coordinate marginal is centred multivariate Gaussian;
- coordinate covariance equals that of `Y 0`;
- uniqueness of `ν` among probability measures with these marginals.

### `IsGaussian` of the whole law

Prove this as a separate corollary. For each continuous linear functional `L`:

\[
L(T_kG)\longrightarrow L(G).
\]

Finite truncations are Gaussian. To identify the limiting variance, use the stronger tail estimate

\[
\|G-T_kG\|_{L^2(\ell^1)}
   \le \sum_{j\notin F_k}\sigma_j.
\]

This follows from Minkowski and the coordinate marginal second moments. Thus `L(T_kG) → L(G)` in L², and the limiting variance is

\[
\operatorname{Var}(L(Y_0)).
\]

Conclude using the dual characterization

`isGaussian_iff_charFunDual_eq`

or the corresponding Gaussian-law API.

This also gives a clean Banach-level covariance identification. It is not necessary to block the downstream continuous-mapping application on this stronger packaging: finite Gaussian marginals plus the CLT already identify the intended limit.

**Non-claim:** this is not an ℓ¹ CLT under `MemLp Y 2` alone. Summable coordinate L² norms are the essential extra hypothesis.

## 7. Construct the actual sample datum, preserving deterministic amplitudes and joint dependence

For phase coefficients `c : Ω → (Fin d → ℕ) → ℝ`, define

\[
Y_\gamma(\omega)=b^{|\gamma|}c_\gamma(\omega).
\]

Require:

- coefficient measurability;
- coordinate `MemLp 2`;
- summability of their weighted L² norms.

Construct the ℓ¹-valued random variable using a.e. absolute summability. If necessary, use a measurable “good set” and assign zero outside it. Export the coordinate identities **a.e.**; do not demand pointwise summability from moment hypotheses.

Then prove

```lean
samplePhase n =
  -- a.e.
  n⁻¹ᐟ² • ∑ i < n, (phaseObservation (X i) - E phaseObservation)
```

with your actual `Real.sqrt` expression.

If `A` is the fixed amplitude datum, define

\[
\mathrm{sampleDatum}_n=\mathrm{phaseEmbed}(S_n)+A,
\qquad
\mathrm{gaussianDatum}=\mathrm{phaseEmbed}(G)+A.
\]

Continuous mapping gives:

```lean
TendstoInDistribution
  sampleDatum atTop gaussianDatum (fun _ => P) ν
```

on `DataSpace d`.

**Amplitude trap:** centring and normalizing the entire pair would erase deterministic amplitudes. The i.i.d. sum concerns the fluctuation coordinates; the amplitude is appended afterward.

**Joint-chart trap:** prove one CLT for the joint observation indexed by a finite disjoint union of chart-coordinate indices. Do not combine marginal chart CLTs as though the charts were independent. They use the same samples, and cross-chart covariance matters.

**Inputs:** measurable composition for sampling, `iIndepFun` transport, `IdentDistrib` transport, existing `ofFamilies`, continuous embeddings into the two summands, continuous mapping.

## 8. Plug-in theorem and an explicit analytic certificate boundary

Finally, instantiate the existing coefficient/remainder convergence theorems with Unit 7. The new public theorem should expose:

1. the certified resolution/chart presentation already required;
2. the i.i.d. sampling law;
3. a concrete analytic/coefficient moment certificate;
4. the existing deterministic expansion hypotheses.

Its conclusion is the joint convergence of the coefficient vector and ordered normalized remainder vector already supported downstream.

### What to derive from an analytic certificate

A useful first certificate is:

- a fixed polydisc radius `R > b > 0`;
- measurable analytic chart observations;
- Taylor coefficient identification;
- an `L²(q)` envelope on that polydisc.

Derive

\[
\|c_\gamma\|_{L^2(q)}
 \le \|M\|_{L^2(q)}R^{-|\gamma|},
\]
and hence
\[
\sum_\gamma b^{|\gamma|}\|c_\gamma\|_{L^2(q)}
 \le \|M\|_2(1-b/R)^{-d}.
\]

For **Taylor coefficients**, this is a geometric Cauchy bound. A factorial belongs to the derivative/coefficient conversion; do not assert an additional `1/γ!` bound without checking the coefficient convention.

### What remains explicit, unless separately proved

Hypothesis I for the original `f` does not automatically become the required envelope for the resolved, divided chart function `a`. The missing bridge may include:

- analytic divisibility and extension after resolution;
- preservation or derivation of an L² envelope;
- a common full-measure set and coefficient measurability;
- identification of the paper’s empirical process with the constructed datum.

Keep these as a named **chart analytic moment certificate** until derived. The additional moment condition involving `sup p(x|w)` is not used by the abstract i.i.d. CLT once the required `L²(q)` bounds are available.

### Tangential versions need a separate check

A scalar-coefficient ℓ¹ CLT does **not** automatically imply a CLT in `C(K, DataSpace)`.

The clean route, where available, is to expand the tangential analytic variables too and construct a larger scalar ℓ¹ datum with a continuous reconstruction map

```lean
largerCoefficientSpace →L[ℝ] C(K, DataSpace d)
```

Then apply continuous mapping. Otherwise, a genuine function-space tightness argument remains. State the chart/joint-chart result first rather than silently claiming this upgrade.

## Stop rule and headline discipline

Stop at the first of these gates that requires an unbounded new project:

- no usable tightness-to-subsequence existence theorem;
- finite-dimensional Gaussian construction requires substantial missing spectral infrastructure;
- the resolved `a` lacks a proved or explicitly assumed L² analytic certificate;
- tangential reconstruction is not available as a continuous map.

At a stop, publish the strongest precise intermediate theorem:

1. **ℓ¹ upgrade with supplied target**;
2. **ℓ¹ i.i.d. CLT under summable coordinate L² norms**;
3. **sample-datum CLT under a chart moment certificate**;
4. **stochastic expansion under that certificate and the certified resolution presentation**.

Only the last two discharge the empirical-data premise of your existing stochastic pipeline. They still must not be described as deriving the paper’s theorem directly from Hypothesis I until the resolved analytic-moment bridge is proved.
