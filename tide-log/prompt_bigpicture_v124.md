So the functional `U ↦ renormFunctional … U` depends on `U|_{face}` = `U ∘ glue J 0` as a function of `w ∈ ℝ^K` — is this the right "tangential" object, i.e. `B_{P,J,a,μ,q} : 𝓓'(ℝ^{K} × Base)` acting on `(s,w) ↦ (∂^a_J obsfam_s)(glue J 0 w)`? The base `s` enters through `ρfam P s`, `obsfam P s` and the base integral — so the natural tangential space is `Base × ℝ^K` (your `FaceSpace P J`); the base is a compact subset of `ℝ^{inactive}` (a box), so `FaceSpace = ℝ^{inactive} × ℝ^K ≅ ℝ^{d − |J|}`.
