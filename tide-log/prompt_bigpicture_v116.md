## 2. My real-variable plan for U2–U3 (please correct/simplify)
Core integral `I_F(N) = ∫_{(0,b]^d} F(v) ∏ v_i^{h_i} e^{−Nβ ∏ v_i^{a_i}} dv`, `a_i = 2k_i`, `F` smooth with bounded derivatives on the box (later `F = χ(s,·)·A(s,·)` with base parameter `s`).
(1) `F = ∏_i (T_i + R_i) F = Σ_{J ⊆ [d]} (∏_{i∈J^c} R_i)(∏_{i∈J} T_i) F`; `(∏_{J} T_i) F = Σ_{m_J < p_J} (∏_{i∈J} v_i^{m_i}/m_i!) · (∂_J^{m} F)(v[J := 0])` (a function of `v_{J^c}` only), and `R_i` for `i ∈ J^c` passes through the `v_J`-monomial (constant along `i`-lines). So `I_F = Σ_J Σ_{m_J} ∫ v_J^{m} G_{J,m}(v_{J^c}) v^h e^{−Nβ v^a}` with `G_{J,m} = (∏_{J^c} R_i)(∂_J^m F|_{v_J=0})`, flat: `|G_{J,m}(v')| ≤ C ∏_{i∈J^c} v_i^{p_i}` (`remList_bound`).
(2) Fubini over the split `J ⊔ J^c`: `∫_{(0,b]^{J^c}} G(v') v'^{h'} Z^{J}_{m}(N v'^{a'}) dv'` with the INNER pure-monomial box integral `Z^J_m(N') = ∫_{(0,b]^J} v_J^{m+h_J} e^{−N'β v_J^{a_J}} dv_J` at the effective size `N' = N ∏_{J^c} v_i^{a_i}`.
(3) Two-regime bound for the inner integral, valid for ALL `N' > 0`: `Z^J_m(N') = Σ_{μ<L} Σ_j c_{μ,j} N'^{−μ} log^j N' + Rem(N')`, with `|Rem(N')| ≤ C N'^{−L}(1+|log N'|)^{|J|−1}` — for `N' ≥ 1` from `taylorTree_cutoff_bound` (rescaled to side `b`), for `N' < 1` from the trivial bounds `|Z| ≤ b^{|m+h|+|J|}` and `|N'^{−μ} log^j N'| ≤ N'^{−L}(1+|log N'|)^j` (μ ≤ L).
(4) Substitute `N'^{−μ} = N^{−μ} v'^{−a'μ}`, `log N' = log N + Σ_{i∈J^c} a_i log v_i`, expand binomially; the coefficient of `N^{−μ} log^q N` is `Σ_{j≥q} c_{μ,j} C(j,q) ∫_{(0,b]^{J^c}} G(v') v'^{h'−a'μ} (Σ a_i log v_i)^{j−q} dv'`, absolutely convergent by flatness when `p_i + h_i + 1 > a_i L` for `i ∈ J^c` (integrability of `v^{c}|log v|^r`, `c > −1`); the remainder `∫ G v'^{h'} Rem(N v'^{a'}) dv' = O(N^{−L}(1+log N)^{|J|−1})` by the same flatness in both regimes.
(5) Sum over `J, m`; `J = ∅` is the fully flat term, bounded directly by the monomial integral with exponents `p+h`, whose candidate exponents all exceed `L` (`dataBoxCoeff_eq_zero_of_not_candidate` ⇒ empty main sum ⇒ `|Z| ≤ C N^{−L}(1+log N)^{d−1}`).
Result: `smoothCoeff F μ q := Σ_J Σ_{m_J} Σ_{j≥q} c^{J,m}_{μ,j} C(j,q) ∫_{(0,b]^{J^c}} G_{J,m} v'^{h'−a'μ} S_{J^c}(v')^{j−q} dv'` and `|I_F(N) − Σ_{μ<L,q} smoothCoeff F μ q N^{−μ} log^q N| ≤ C_L(‖F‖_{mixed,p}) N^{−L}(1+log N)^{d−1}` for `N ≥ 1`. (This is Astra #114's Laurent formula in real-variable form; the `c^{J,m}` are the existing monomial coefficients.)
